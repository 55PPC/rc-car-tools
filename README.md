# RC Car Tools · RC 遥控车研发计算工具

在线使用：https://55ppc.github.io/rc-car-tools/

| 文件 | 说明 |
|---|---|
| `index.html` | 网页版计算器，浏览器直接打开即可 |
| `rc_calc.py` | Python 命令行版（仅标准库）：`python3 rc_calc.py`，示例 `python3 rc_calc.py --demo` |

包含：
- 动力：齿比 / 总减速比 / Rollout、车速、推力、反推马达齿；多级减速链（直齿 / 伞齿）与齿面接触强度
- 强度：Lewis 齿轮弯曲、轴扭转、转矩流（名义 / 峰值载荷、逐件安全系数）、中轴临界转速与万向节、横销与轮毂承压、螺纹预紧扭矩、轴承 L10 寿命
- 整车：电池续航、轴荷重心侧翻、质量预算、悬架弹簧（频率 / 刚度 / 并圈 / 阻尼）、阿克曼转向、舵机扭矩
- 研发流程：任务书目标与达标看板、实测记录与理论校准、G0–G7 评审节点与红线问题、车型存档与两车对比（JSON 导出 / 导入）
- 数据：带来源标注的材料库；历史 BOM 导入、材料写法自动提示与人工核查

> 所有结果均为理论值 / 初步估算，请与实测数据分开记录、对照修正；材料强度为参考值，以材料数据表为准。
