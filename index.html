逐级校核

弯曲：σF = K · Ft / (b · m · Y)，SF = 材料强度 ÷ σF。接触：σH = ZE · ZH · √(K · Ft / (b · d₁) · (u + 1) / u)，ZH = 2.5（20° 标准齿），ZE 由两齿轮弹性模量算出；SF = 许用接触应力 ÷ σH。伞齿按背锥当量直齿处理：中点模数 mm = m(1 − 0.5b/R)，当量齿数 zv = z / cos δ，当量齿数比 uv = u²。逐级转矩按无损传递（偏保守）。这是初步校核，不能替代 ISO 6336 / AGMA 的完整计算。

各材料安全系数

SF = 屈服强度（塑料取拉伸强度）÷ σ · 竖线为 SF 2

铜齿取半硬棒材的参考屈服强度：H62 约 250 MPa（1/2H 状态下限），铅黄铜 HPb59-1 / C3604 约 170 MPa（参照 C36000 半硬棒材的最低屈服值），牌号和状态不同差异很大。塑料齿轮还需考虑温升、蠕变、疲劳，SF 宜 ≥ 2–3。材料强度为常见参考值，以供应商数据表为准。

说明

「标准最低值」取自国标 / ISO 等标准规定的最低保证值，可直接用于校核；「典型值」是手册或厂商的常见值，同一牌号不同批次、状态差异大，正式定版前要换成供应商材料证明书上的数据。塑料无明显屈服点，取拉伸强度参考值，吸湿、温升后会明显下降。

横销 · 轮毂承压六角轮座横销、狗骨销等十字销传扭

销剪切按双剪：τ = 4T / (π · d² · D)，D 为轴径；许用剪应力取 0.5σs。轮毂槽承压：每侧受力 F = T / (2 · r)，p = F / (d · L)，与轮毂材料强度比较。横孔会削弱轴：孔处应力集中系数约 1.5–2，轴强度页的结果要按此打折。

螺纹预紧 · 拧紧扭矩公制粗牙，按强度等级与预紧比例

全部规格对照

拧紧扭矩 T = K · F · d，K 为扭矩系数（干燥钢件约 0.2，加螺纹胶或润滑约 0.15–0.18）。旋合长度经验：钢螺母 ≥ 0.8d；铝件攻丝 ≥ 1.5–2d；塑料件不宜直接攻丝反复拆装，建议用嵌件或自攻结构，且扭矩要按塑料能承受的值另定。

轴承寿命 L10深沟球轴承，按当量动载荷估算

L10 = (C / P)³ × 10⁶ 转，P = 载荷系数 × max(Fr, 0.56Fr + 1.6Fa)（深沟球轴承近似）。预设额定动载荷 C 参考 SKF 样本，不同品牌和密封形式差别很大，请按实际供应商样本填写。RC 车轴承多因进沙、进水和冲击压痕提前失效，计算寿命只代表干净润滑条件。

轴荷取自「车身 · 重心」页称重；运动比 MR = 避震行程 ÷ 车轮行程

目标轮端刚度 k轮 = m簧上 · (2πf)²；弹簧刚度 k = k轮 ÷ MR²；弹簧实际刚度 k = G·d⁴ / (8·D³·n)。剪应力按 Wahl 修正 τ = Kw · 8FD / (πd³)，许用取 0.45 Rm（静载，疲劳要更低）。实车 1/10 车身频率常见 3–6 Hz（全尺寸车 1–2 Hz 按比例放大）。阻尼按临界阻尼的比例给出建议值，实际要靠活塞孔径和油的黏度调出来。

舵机扭矩估算原地转向（最恶劣的静摩擦工况）

单轮原地转向阻力矩 M = μ · N · √(B²/8 + e²)（轮胎接地面绕主销扭转 + 主销偏距产生的力臂，常用经验式）。舵机扭矩 = 2M ÷ 转向臂长 × 舵机摆臂半径 × 余量。只算静态，行驶中的回正力矩一般更小，但颠簸、撞路肩的冲击可能更大，所以选型要留余量，并配合舵机保护器。
